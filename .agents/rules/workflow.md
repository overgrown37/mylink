# Workflow Rules: Implementation Plan & Walkthrough

### 작업 프로세스 원칙
1. **작업 시작 전 (Implementation Plan)**:
   - 모든 작업 시작 전 항상 `implementation_plan.md` 아티팩트를 먼저 작성하고 사용자 승인을 받을 것.
   - 아티팩트에는 목표, 변경 파일, 상세 단계, 검증 계획을 명시하고 `RequestFeedback: true`로 설정할 것.
   - 사용자 승인(Proceed) 전에는 임의로 코드를 수정하거나 실행하지 말 것.

2. **작업 완료 후 (Walkthrough)**:
   - 작업 완료 후 항상 `walkthrough.md` 아티팩트를 작성할 것.
   - 변경된 파일 목록(클릭 가능한 링크), 주요 구현 내용, 동작 검증/테스트 결과를 명확히 정리하여 보고할 것.
